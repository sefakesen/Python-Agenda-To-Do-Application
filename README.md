# 📅 Python Agenda & To-Do Application

Bu proje, Python kullanılarak geliştirilmiş, görevlerinizi önem derecesine ve tarihe göre organize etmenizi sağlayan modern arayüzlü bir ajanda uygulamasıdır.

## 🚀 Özellikler
* **Akıllı Sıralama:** Eklenen görevler, belirlenen hedef tarihe ve öncelik derecesine (Düşük, Orta, Yüksek vb.) göre otomatik olarak sıralanır.
* **Modern Kullanıcı Arayüzü:** Standart Tkinter yerine `CustomTkinter` kullanılarak koyu/açık tema destekli ve estetik bir arayüz tasarlanmıştır.
* **Yerel Veri Depolama:** Görev verileri, herhangi bir dış veri tabanı sunucusuna ihtiyaç duyulmadan yerel olarak `JSON` formatında güvenle saklanır ve hızlıca okunur.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** Python 3.x
* **GUI (Arayüz):** CustomTkinter, Tkinter
* **Veri Tabanı:** JSON (Yerel Dosya İşleme)
* **Yardımcı Modüller:** `os`, `re` (Düzenli ifadeler ve dosya yolu kontrolleri için)
